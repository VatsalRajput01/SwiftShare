How to Use SwiftShare

Welcome to SwiftShare! Our service is designed for fast, simple, and secure file sharing. Here’s how to get started.

1. How to Send (Upload) a File

  1. On the Upload page, either drag and drop your file(s) into the dashed box or click the box to browse your computer.
  2. Once you select a file, the Options Menu will appear below it.
  3. (Optional) Set Password : You can add a password for extra security. The receiver must enter this password to download the file.
  4. (Optional) Set Limits : Choose the maximum number of downloads (e.g., 1, 2, or 5) and when the file expires (e.g., 1 hour, 6 hours, 24 hours).
  5. Click the "Upload" button.
  6. After the upload is complete, you will see a success message with your unique 8-character Download Code (example : `1234-ABCD`).

Important : You must share this Download Code or the Download Link with the person you want to send the file to.

2. How to Receive (Download) a File

  1. Go to the Download page (or click the download link you received).
  2. Enter the 8-character Download Code into the boxes.
  3. Click the "Verify Code" or "Download" button.
  4. If the file is password-protected, you will be asked to enter the password.
  5. Your download will begin.

Key Features & Security

  • No Account Needed : Share files instantly without needing to sign up or log in.
  • Privacy First : Your files are private. Once they expire or reach their download limit, they are permanently deleted from our servers.
  • Password Protection : Add a layer of security to sensitive files.
  • Full Control : You decide who gets the code, how long the file lasts, and how many times it can be downloaded.
