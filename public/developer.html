Our Core Philosophy (The Motivation)

The motivation behind SwiftShare was simple : File sharing should be frictionless and private. Having observed complications and data issues with existing services in daily life, the goal was to build a simple, private file-sharing platform that puts the user in control of their data's lifespan and accessibility.

Technology Stack

SwiftShare is built on a modern and efficient JavaScript-based technology stack to ensure high performance and reliability.

Frontend Technologies :

  • HTML5 & CSS3 : For the core structure and styling.
  • Tailwind CSS : Used as a utility-first framework for rapid and consistent design.
  • JavaScript (Vanilla JS) : Used for all client-side logic, including the interactive theme toggle, file validation, and file selection handlers.
  • Alert Libraries (Future) : Ready to integrate libraries like SweetAlert2 or Toastr for clean, modern notifications.

Backend & Infrastructure :

  • Node.js & Express.js : Powering the server-side logic for high-speed routing and handling file transfers efficiently.
  • Multer : Used as middleware for robust handling of multipart file uploads.
  • Cloudflare : Utilized for scalable storage and reliable global file handling.
  • Node Modules : Uses built-in modules like `Crypto` for secure operations (like password hashing, if implemented) and `fs` for file system management.
  • Automation : Uses `cron` or `node-cron` for scheduling tasks like automatic file deletion (cleanup).

Security & Privacy Features Implemented

  • File Size Limit : A 500 MB limit is enforced to maintain server stability, speed, and overall privacy.
  • Access Control : Implemented via unique 8-character codes and optional password protection.
  • Data Minimization : Strict auto-deletion policy based on set expiry hours or maximum download count.
