Our Approach to File Security

At SwiftShare, we focus on access control and data minimization to ensure your files are shared privately and reliably. Our key security measures ensure that only the intended recipient, with the correct code and optional password, can access the file before it is permanently deleted.

Secure Transmission and Access Control

1. Secure Transmission (HTTPS)

All data exchanged between your browser and the SwiftShare server—including the file itself, the optional password, and the download code—is secured using SSL/TLS (HTTPS). This standard internet security protocol creates an encrypted tunnel to prevent eavesdropping while the data is in transit.

2. Unique Access Code

Every upload is assigned a unique, 8-character code (e.g., `1234-ABCD`). This code is the only key to access the file's download page. Without this code, the file cannot be located on our system.

3. Optional Password Protection

For an extra layer of security, you can set an optional password during the upload process. When a file is password-protected, the recipient must provide both the correct 8-character code and the password to initiate the download.

Data Minimization and Deletion Policy

Our most important privacy feature is our commitment to not permanently storing your data. Once the share purpose is served, the file is automatically and immediately deleted.

  • Deletion by Expiration : You set an expiration time (e.g., 1 hour, 24 hours). Once this time limit is reached, your file is permanently and irretrievably deleted from our server storage.
  • Deletion by Download Limit : You can set a maximum download count (e.g., 1 download, 5 downloads). When the file has been downloaded that many times, it is permanently deleted, regardless of the expiration time.
  • No File Backup : We do not keep backups of expired or deleted files. Once a file is removed, it is gone for good.

Privacy Policy Highlights

  • No Accounts : We never ask for, collect, or store personal identifying information like names or email addresses.
  • No File Scanning : We do not inspect or monitor the contents of the files you share.
